# Examples

This directory contains example scripts demonstrating various features of the book search system.

## Files

- `audioEval.py` - Audio evaluation and processing example
- `gemini-audio-test.py` - Gemini AI audio processing test example

## Usage

### Audio Evaluation

```bash
python examples/audioEval.py
```

### Gemini Audio Test

```bash
python examples/gemini-audio-test.py
```

## Requirements

These examples may require additional dependencies beyond the core library. Make sure to install all requirements:

```bash
pip install -r requirements.txt
```
